# 🧮 Modern Calculator

A sleek and responsive calculator built with **HTML, CSS, and JavaScript**. This project features live result preview, keyboard shortcuts, calculation history, dark mode, and smooth UI interactions. It was developed as part of the **CodeAlpha Frontend Development Internship**.

---

## ✨ Features

- 🧮 Perform basic arithmetic operations (+, −, ×, ÷, %)
- ⚡ Live result preview while typing
- ⌨️ Keyboard support
- 🌙 Dark & Light mode toggle
- 🗂️ Calculation history
- 💾 History saved using Local Storage
- 🗑️ Clear (AC) and Delete (DEL) functionality
- 📱 Fully responsive design
- 🎨 Modern user interface with smooth button animations

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
